README 抜粋

atlas-lm is a serving stack that puts routing, caching and evaluation behind one endpoint. It speaks the OpenAI wire format, so existing clients work unchanged. The router picks a backend per request from latency and cost budgets you declare in a single YAML file, and every response is recorded so you can replay a week of production traffic against a candidate model before switching.
